# Novel Writing

## Overview
Create coherent long-form fiction by clarifying requirements, designing narrative elements, drafting scenes, and revising for consistency, pacing, and voice.

## Workflow

### 1) Clarify the brief
- Ask for genre, target audience, length (word count or chapters), tone, and language.
- Ask for required elements (setting, themes, tropes, content limits).
- Confirm point of view and tense preferences.
- If psychological themes are central, ask which concepts should shape the protagonist’s choices.

### 2) Build the story foundation
- Define a one-sentence premise and a paragraph summary.
- Identify protagonist goal, stakes, and central conflict.
- Decide on structure (three-act, four-act, episodic) based on length.
- Map the internal arc to external events (how beliefs change with each turning point).

### 3) Design characters and setting
- Create character profiles: role, motivation, flaw, arc, relationships.
- Map key relationships and conflicts.
- Establish setting rules, mood, and constraints that shape the plot.
- For psychology-driven stories, show how the setting enables or blocks coping strategies.

### 4) Outline and scene plan
- Produce a chapter/scene outline with turning points.
- For each scene, specify: goal, conflict, change, and hook.
- Balance exposition, action, and reflection to control pacing.
- For growth arcs, tag scenes as “insight,” “practice,” or “relapse” to track progress.

### 5) Draft scenes
- Write scenes in full prose with sensory detail and internality.
- Maintain voice consistency and avoid repetitive beats.
- Use dialogue to reveal character intent and subtext.
- Show psychological techniques through action and decisions, not lectures.

### 6) Revise and polish
- Check continuity (timeline, names, causality).
- Tighten pacing by cutting redundant exposition.
- Strengthen theme by echoing motifs and character choices.
- Provide a clean final draft or an edit list with priorities.

## Output Patterns
- If the user wants planning: deliver premise → outline → scene list.
- If the user wants prose: draft scenes with clear scene breaks.
- If the user wants revision: return a short critique + targeted rewrites.

## Quality Checklist
- Premise is clear and stakes escalate.
- Character actions align with motivations.
- Each scene changes the situation or character state.
- Tone and point of view remain consistent.
- Psychological elements are dramatized through choices and consequences.
